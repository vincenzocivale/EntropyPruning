# EAGLE benchmark replication (labeled WSI evaluation cohorts)

This document tracks reproduction of the labeled WSI benchmark used in
**EAGLE — "A deep learning framework for efficient pathology image
analysis"** (Neidlinger et al., *Nature Communications* 2026;
[arXiv:2502.13027](https://arxiv.org/abs/2502.13027);
[github.com/KatherLab/EAGLE](https://github.com/KatherLab/EAGLE)), so that
FMs fine-tuned/pruned with this repo's EAF method can be evaluated for
maximum comparability with EAGLE's reported numbers.

## Paper's main benchmark (Fig. 1a)

13 cohorts, 9,528 WSIs, 4 cancer types, 31 externally-validated tasks
(morphology, biomarker, prognosis), five-fold CV trained on TCGA, evaluated
on the full external cohorts.

| Cancer | TCGA (train, 5-fold CV) | External arm 1 | External arm 2 |
|---|---|---|---|
| CRC | n=566 | CPTAC n=220 | **DACHS n=3604** (private, DKFZ) |
| BRCA | n=1093 | CPTAC n=395 | **IEO n=451** (private, Milan) |
| STAD | n=350 | **Bern n=501** (private) | **Kiel n=320** (private) |
| NSCLC | LUAD n=524 / LUSC n=493 | CPTAC n=498 (LUAD) / n=478 (LUSC) | — |

## What we reproduce vs. what we don't

**DACHS, IEO, Bern, and Kiel are private institutional cohorts with no
public download path** — they require a formal data-access/collaboration
agreement with DKFZ, IEO Milan, Bern, and Kiel respectively. This is a
confirmed, permanent gap, not a to-do: full 13/13-cohort parity is not
achievable by download. Decision confirmed with the user 2026-08-23.

We reproduce the **9 public cohorts** (5 TCGA projects + 4 CPTAC
collections), covering all 4 cancer types:

| Cancer | TCGA arm | CPTAC (IDC) arm |
|---|---|---|
| CRC | `TCGA-COAD` + `TCGA-READ` | `cptac_coad` |
| BRCA | `TCGA-BRCA` | `cptac_brca` |
| STAD | `TCGA-STAD` | *(none — paper used Bern/Kiel, not CPTAC)* |
| NSCLC | `TCGA-LUAD` + `TCGA-LUSC` | `cptac_luad` + `cptac_lscc` |

Evaluating a model on this reduced set is a lower bound / partial
replication of the paper's external validation; it is not equivalent to the
full 13-cohort benchmark. Any comparison against numbers reported in the
paper should say explicitly which arms were used.

## Task/label scope: "core via API" (this pass)

Ground truth is pulled from the public cBioPortal REST API
(`https://www.cbioportal.org/api`, no auth) and GDC clinical data — labels
that are exposed as structured clinical/mutation attributes. Per user
decision 2026-08-23, tasks whose labels only exist in a paper's supplementary
tables (not queryable via API) are **out of scope for this pass**:

- **STAD EBV status / Lauren classification** — TCGA-STAD paper (Bass et al.
  2014) supplementary Table 2 only, not in cBioPortal/GDC clinical fields.
  Not attempted here.
- **CRC CIMP status** — same category; attempt via cBioPortal first, drop if
  unavailable.

Tasks expected to be reachable via API:

| Cancer | Tasks |
|---|---|
| CRC | MSI status/score, BRAF mutation, KRAS mutation, AJCC M-status, AJCC N-status |
| BRCA | ER status (IHC), PGR status (IHC), ERBB2/HER2 status, PIK3CA mutation |
| NSCLC | LUAD-vs-LUSC subtyping (no label fetch needed — it's the GDC project), EGFR mutation, STK11 mutation, TP53 mutation |
| STAD | TP53 mutation, MSI status (if present for TCGA-STAD in cBioPortal); EBV/Lauren excluded per above |

Exact study IDs and per-task availability (including whether a CPTAC
cBioPortal study exists for a given cohort) are finalized in
`scripts/wsi_data/build_eagle_benchmark_labels.py` at implementation time;
any task that turns out not to be reachable is recorded there and in this
doc rather than silently dropped.

## Directory layout

Follows `docs/data_layout.md` exactly — this is `downstream`, not
`pretraining`, data:

```text
$EAF_WSI_ROOT/
├── sources/gdc/tcga/{BRCA,COAD,READ,STAD,LUAD,LUSC}/   # one physical copy, shared with any other consumer
├── sources/idc/cptac/{cptac_brca,cptac_coad,cptac_luad,cptac_lscc}/
├── datasets/downstream/wsi_level/
│   ├── eagle_tcga_v1/
│   │   ├── manifests/{slides.csv, gdc_manifest per project}
│   │   ├── views/raw_flat/*.svs -> ../../../../../sources/gdc/tcga/...
│   │   ├── artifacts/trident/20x_512px_0px_overlap/patches/*.h5
│   │   └── labels/<task>.csv
│   └── eagle_cptac_v1/
│       ├── manifests/
│       ├── views/
│       ├── artifacts/

```

Raw pixels have exactly one physical copy under `sources/`; dataset views are
symlinks (per the raw-source rules in `docs/data_layout.md`).

## Patho-Bench extension (added 2026-08-23)

EAGLE also reports results on **Patho-Bench**
(`huggingface.co/datasets/MahmoodLab/Patho-Bench`, Vaidya et al. 2025 /
Zhang et al. 2025) — 12 survival/treatment-response tasks across 7
additional cancer types, no external cohorts (internal 80/20 splits).
Patho-Bench itself is **public, not gated, 13.5 MB** — splits/labels only,
already downloaded to
`datasets/downstream/wsi_level/pathobench_v1/splits/` — but the raw WSIs for
each of its 12 tasks live in the original source repository per task. Per
user decision (2026-08-23), CPTAC-sourced Patho-Bench tasks reuse
Patho-Bench's own published labels/splits instead of a fresh cBioPortal
pull; TCGA-only tasks (main benchmark) still use cBioPortal.

Source accessibility for the 6 standalone (non-CPTAC) cohorts, checked
2026-08-23:

| Cohort | Task(s) | Source | Access |
|---|---|---|---|
| SURGEN (`sr386_`) | OS, 5y mortality, BRAF/RAS/MMR | EBI BioImage Archive `S-BIAD1285` | **Public**, wget/FTP, no registration — 1,020 WSIs, largest public CRC WSI set |
| OV-Bevacizumab (`ovarian`) | bevacizumab response | TCIA `OVARIAN-BEVACIZUMAB-RESPONSE` | **Public**, standard TCIA click-through (like CPTAC) |
| NADT-Prostate (`nadt`) | hormonal therapy response | TCIA `NADT-PROSTATE` | **Public**, standard TCIA click-through |
| POST-NAT-BRCA (`natbrca`) | lymphovascular invasion | TCIA `POST-NAT-BRCA` | **Public**, standard TCIA click-through |
| BOEHMK (`boehmk_`) | PFS (ovarian) | Synapse `syn25946117` | Free Synapse account + click-through "Conditions for Use"; exact terms not yet confirmed by attempting access |
| MBC (`mbc_`) | OS, RECIST (metastatic breast) | Synapse `syn59490671` | Free Synapse account + click-through "Conditions for Use"; exact terms not yet confirmed by attempting access |

4 of 6 standalone cohorts are as accessible as TCGA/CPTAC (no institutional
DUA). BOEHMK/MBC need a Synapse account and accepting a per-dataset
click-through agreement — still not comparable to DACHS/Bern/Kiel/IEO's
PI-mediated process, but not yet verified to be frictionless either; confirm
by attempting download before counting on them.

The CPTAC-sourced Patho-Bench tasks (LUAD, HNSC, PDAC, CCRCC — survival;
plus many more mutation/subtyping tasks in the 95-task full set) reuse the
same `sources/idc/cptac/` acquisition as the main benchmark; Phase F adds
`cptac_hnsc`, `cptac_pda`(`pdac`), `cptac_ccrcc` to the IDC discovery list
alongside the 4 already planned (`cptac_brca`, `cptac_coad`, `cptac_luad`,
`cptac_lscc`).
